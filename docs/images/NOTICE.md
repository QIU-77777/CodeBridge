# 截图说明

这两张 PNG 是 README「它长什么样」一节用的产品图：

- `request-and-reply.png` — 发起请求与接收回复（含 markdown 表格渲染）
- `session-switch.png` — 多会话管理（`/cd` / `/sessions` / 切换）

## 已做脱敏

原图来自一台装了终端管控软件的机器，直接发布有两层问题，都已在交付版本里处理掉：

**1. 满屏半透明 DLP 水印**

背景上重复叠着姓名、账号和内网 IP。处理方式是中值滤波估计局部底色，把偏离底色不足阈值的像素替换成底色，文字因对比度高而保留。处理后水印不可读。

**2. 账号、主机名与绝对路径**

图里出现的公司账号名、主机名、`/Users/<账号>/...` 绝对路径，都换成了同字号的占位内容（账号统一为 `demo-user-00001`）。替换文字用 14px 的 STHeiti Light（中文）与 Helvetica（西文）原地重绘，字号、基线、行距与原图一致，所以卡片版式不受影响。

**注意：缩图不等于脱敏。** 原始文件是 1294×1711，即便按 520px 高度展示，放大原图仍可读。上面两步是在原始分辨率上做的，不是先缩小再遮盖。
